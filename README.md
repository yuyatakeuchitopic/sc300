SC-300 模擬問題(HTML版、EXE版)

・問題は2026/10現在基準で、古すぎてシラバスから外れている問題や、終了したサービスを扱っている問題を除外しています。

・ブラウザー(Edge / Chrome / Firefox)で開くだけで使えます。
インストールやインターネット接続は不要です。

・アプリ版は機能はブラウザ版と変わりません。
・動作はhtml版と変わりませんが、誤ってブラウザのタブを消して学習データを消してしまうことはありません。（ローカルにデータ保存）
・好みで使い分けてください

・学習記録は、使用しているブラウザーの中に保存されます。別のブラウザーや PC へ移すときは、画面右上の「書き出し」「読み込み」を使ってください。

・ブラウザーの閲覧データ(サイトデータ)を消去すると、記録も消えます。定期的に「書き出し」で保存しておくと安心です。

・index.html を別の場所へ移動・コピーすると、ブラウザーによっては記録が引き継がれません(その場合も書き出し/読み込みで移せます)。
